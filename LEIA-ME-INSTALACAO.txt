MENSAGENS PARA O MUNDO — ATUALIZADO ATÉ 01/08/2026

Este pacote contém:
- index.html: acervo acumulativo com as mensagens revisadas até 01/08/2026.
- manifest.json: identificação do aplicativo instalável.
- sw.js: serviço de cache offline (versão v6 para renovar o cache dos dispositivos).
- icon-180.png, icon-192.png e icon-512.png: ícones do aplicativo.

- Layout responsivo, botão de instalação direta, pesquisa, navegação e notas anteriores preservados.

PUBLICAÇÃO NO GITHUB PAGES
1. Extraia todos os arquivos.
2. Envie todos os arquivos juntos para a pasta publicada pelo GitHub Pages.
3. Mantenha index.html na raiz da pasta publicada.
4. Aguarde a publicação e abra o endereço HTTPS.
5. Atualize a página. O novo cache v6 substitui o anterior.

INSTALAÇÃO
- Computador/Android: use o botão “Instalar app” no cabeçalho; o navegador apresentará a confirmação quando suportado.
- iPhone/iPad: no Safari, toque em Compartilhar e depois em “Adicionar à Tela de Início”.

A instalação PWA exige publicação em HTTPS (ou localhost durante desenvolvimento). O HTML aberto diretamente como arquivo local não pode instalar o PWA nem usar o serviço offline.
